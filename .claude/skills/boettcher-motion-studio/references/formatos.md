# Formatos para Boettcher

## A. Captación de propietarios (15-20 segundos)
0-2 s: pregunta o dolor concreto. 2-7 s: problema visible. 7-14 s: solución verificable del servicio. 14-20 s: CTA para consulta o tasación.
Ejemplo de gancho: «¿Su propiedad lleva semanas sin arrendarse?» Nunca prometer tiempos fijos sin validación del caso.

## B. Tour comercial (18-30 segundos)
0-2 s: primer plano visual potente de una habitación real. 2-14 s: mejores espacios con datos confirmados. 14-23 s: ubicación, precio y condiciones si están aprobados. Últimos 3 s: CTA para coordinar visita.

## C. Educativo (15-25 segundos)
0-3 s: error frecuente o pregunta precisa. 3-18 s: dos aclaraciones prácticas. Últimos segundos: invitación a conversar. Las obligaciones legales deben revisarse con normativa chilena vigente, caso por caso.

## D. Cinemático / tendencia (12-18 segundos)
0 s: impacto visual inmediato. 1-10 s: cortes 0.5-1.8 s y palabras cortas. 10-15 s: revelación/resultado. 15-18 s: CTA muy corto. Nunca copiar el montaje exacto de un creador.

## Entregables
Un MP4 vertical si el entorno permite renderizar, más guion, variantes de gancho, copy de publicación y lista de assets requeridos. Variantes para 1:1 y 16:9 solo cuando se soliciten.
