# Estructuras de narración

## Secuencia problema → consecuencia → decisión → solución
0-3 s: hecho específico y pregunta implícita.
3-12 s: microescena con sujeto y acción.
12-25 s: muestra consecuencias verificables; ejemplo monetario solo si se etiqueta.
25-40 s: explicar qué se puede hacer y cómo lo gestiona Boettcher.
40-55 s: una prueba/servicio verificable (no prometer protección universal).
55-60 s: CTA natural.
Ajustar el mapa al audio REAL: los tiempos anteriores son orientativos.

## Secuencia error → sorpresa → solución
Mostrar primero un error usual, hacer visible la consecuencia, explicar la conducta correcta, invitar a consulta si aplica.

## Secuencia pregunta de propietario → respuesta
Usar la pregunta literal como gancho, resolverla temprano, explicar el límite legal o contractual, cerrar con utilidad concreta.

## Entrega de beats
Por cada beat: start_estimado, idea_oral, elemento_visual, acción_en_pantalla, motivo_de_atención, cue_texto, fundamento_de_dato. No presentar el tiempo estimado como alineación definitiva; recalcular con WAV/MP3.
