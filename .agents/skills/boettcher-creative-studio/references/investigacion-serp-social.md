# Investigación SERP + redes con evidencia

## Inputs
Pregunta comercial; público; Chile / ciudad; fecha; objetivos (leads/seguidores/educación); enlaces de referencia; acceso permitido. Nunca buscar a ciegas con un único hashtag genérico.

## Google / web
1. Formar 3-5 consultas: literal, problema, comparación, pregunta y costo. Ejemplo: «qué hacer si arrendatario no paga Chile», «administración propiedades seguro arriendo Chile», «cuánto demora demanda arrendamiento Chile».
2. Buscar con método autorizado, documentar consulta, país, fecha y orden OBSERVADO. Analizar mínimo 3 páginas legibles, hasta 5. Distinguir anuncios de resultados orgánicos; no afirmar que una página es «número 1 en Google» si la posición no fue observada en los parámetros indicados.
3. Extraer sólo ideas: preguntas recurrentes, lenguaje utilizado por propietarios, objeciones, conceptos confusos, fuentes legales, cifras verificadas. Sintetizar, no copiar párrafos ni estructura textual de un competidor.
4. Contrastar los datos de Boettcher con su sitio oficial y documentos de planes. Para legislación chilena, contrastar con fuente legal vigente.

## Instagram / TikTok / Shorts
1. Buscar temas concretos y creadores del nicho mediante acceso autorizado, Creative Center y/o enlaces suministrados. No usar scraping, contraseñas ni cookies de sesión.
2. Para cada video observar: URL, plataforma, fecha, visualizaciones, likes, comentarios, compartidos, duración, primeros 3 s, estructura, tipo de narrador, metáfora y CTA. Anotar «no visible» donde corresponda.
3. Al comparar rendimiento controlar aproximadamente fecha, tamaño de cuenta, alcance y período de observación; views no equivalen a leads. Si faltan datos comparables, NO ordenar por «más viral» de manera concluyente.
4. Detectar patrones mediante evidencia de varias piezas. Separar: dato medido / observación directa / hipótesis creativa.
5. Resumir 3 propuestas originales para Boettcher, cada una con ángulo, hook, estructura, visuales y diferencia respecto de las referencias.

## Accesos y permisos
La API oficial de Instagram sirve para métricas de la cuenta propia profesional y algunas funciones de descubrimiento público sujetas a permisos y límites; no ofrece un buscador irrestricto de todos los Reels. Obtener autorización mediante OAuth legítimo. Nunca pedir credenciales directas. Los reels aportados manualmente se pueden inspeccionar si el archivo o enlace es accesible; reproducir técnicas narrativas, no imágenes/voz/guion protegidos.

## Respuesta ante datos insuficientes
Entregar resultado parcial respaldado, declarar huecos y producir concepto sin prometer viralidad; no bloquear todo el trabajo esperando datos perfectos.
