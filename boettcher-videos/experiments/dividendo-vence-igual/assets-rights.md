# Recursos del piloto

| Recurso | Procedencia |
| --- | --- |
| Guion y textos | Escritos para Boettcher. Las fuentes consultadas sustentan los datos comerciales y legales. |
| Gráficos y animación | Elementos originales dibujados en el proyecto Remotion. |
| Diseño sonoro | Tonos generados localmente por `audio.py`. |
| Marca | Nombre comercial Boettcher Propiedades aportado para el proyecto. |

La muestra de revisión tiene texto animado y diseño sonoro. La locución definitiva se incorporará con el audio autorizado del proyecto.
